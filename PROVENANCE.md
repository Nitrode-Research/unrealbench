# Provenance

The 14 Unreal packages include material imported from UnrealBench / GameEngineBench
and NightSkyEngine, together with Nitrode packaging, verification and regrade work.
They are not all clean-room implementations. Per-task provenance documents and
source receipts record the original source identities and commits.

On 2026-09-18 the repository owner confirmed redistribution rights for the
14-task public benchmark. Existing third-party notices and license files remain
applicable and are retained. Earlier per-task notes requesting redistribution
confirmation are historical; this statement records the owner's confirmation.
It does not replace third-party license terms or grant access to Epic binaries.

Unreal Engine images are obtained separately through Epic's distribution.
The owner selected Apache-2.0 for Nitrode-owned code and task content on
2026-09-18. See LICENSE and NOTICE; existing third-party terms remain in effect.
SOURCE.json identifies the development snapshot used for this candidate, and
RELEASE_REPORT.json records exported file hashes.
