# Battle checkpoints

`ANightSkyGameState::ExportCheckpoint()` returns the checkpoint bytes of the live battle. `ANightSkyGameState::ImportCheckpoint(Bytes)` replaces the live battle's gameplay state from such bytes and returns `EBattleCheckpointResult`: `Restored`, `Malformed`, `UnsupportedVersion` or `LineupMismatch`. `BattleCheckpointVersion` is the schema version the current build writes and accepts. Both operations are declared in `Battle/NightSkyGameState.h` and defined in `Battle/BattleCheckpoint.cpp`; the starter versions are placeholders. `SaveGameState` and `LoadGameState` keep their rollback behaviour and signatures. A lineup is the roster and capacities only (players per side and their classes, pool capacity, extensions by class and name, ordered); per-player runtime assignments such as `TeamIndex` are mutable gameplay state the import restores, not part of the lineup.

`Fixtures/NSE010Fixture.{h,cpp}` is neutral authoring support. `FNSE010Battle` builds a real battle in a private world from an `FNSE010Lineup` (team sizes, pool capacity, an alternate player class for the second side, an optional battle extension). `Step(Input1, Input2)` runs the engine's battle frame. `Reset()` returns a battle to the state it had when built, through the engine's own rollback snapshot, and clears `Trace`. Player scripts keep the body hurtbox set, walk on Left and Right and spawn a shot on an A press; shot scripts travel, arm their hitbox on the first execution and log hits. `Script(Object)` returns the live script of a player or pooled object, `ShotTemplate(Owner)` the registered shot script that spawns copy, `Spawn(Owner, X, Y)` a pooled shot, `Store(Owner, Object, Index)` a stored child reference, `Extension()` the optional extension. Script fields such as `DriftX`, `RandomWalk`, `FreezeAtCounter`, `FollowStoredIndex`, `Damage`, `bDeactivateOnHit` and `TraceId` are ordinary saved state. `Trace` logs callbacks in engine order: `TraceId` on hit or block, `-(TraceId + 1)` on receive, `5000 + TraceId` on super freeze end. `Find(GameState)` maps a game state back to its fixture.
