Implement the native gameplay for an immersive sim set inside a powered facility. The player should be able to manipulate power and machinery, collect tools, bypass security, climb and hide, escape through the MainGate or ServiceTunnel, and start a new attempt. Read `/project/gdd.md` before coding. It describes the game systems, their interactions, acceptance scenarios and editable files. Implement both facility simulation and player systems in the supplied architecture. Keep the existing headers, APIs, components, maps and assets intact. Use local builds and tests to check your work; submit only changes to the listed implementation files.
