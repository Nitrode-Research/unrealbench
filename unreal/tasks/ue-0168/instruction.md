Implement the faction simulation and AI strategy for the supplied two-faction RTS. Each faction should deploy its command vehicle, build an economy and base, produce an army, reclaim wrecks, and fight toward a single match outcome. Read `/project/gdd.md` for the game design, implementation details and editable files. Unit combat, controls and presentation are supplied; connect your systems to them and preserve their behavior. Use the existing native subsystems and configured costs, timings and limits. Validate through local builds and tests, then submit changes only to the listed files.
